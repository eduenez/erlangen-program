The function w = eᶻ

Infinitely many inputs, one output.

Move z. Its real part sets the size of eᶻ and its imaginary part sets the angle — so going up by 2π changes nothing.

Input z = x + iy

Drag z. The teal segment has height 2π; dashed lines cut the plane into strips of that height.

Output w = eᶻ

The vertical line through z wraps around the teal circle of radius eˣ, once for each segment of height 2π. The horizontal line through z becomes the rose ray. Dashed: the unit circle.

Why can no polynomial equation relate z and eᶻ?

Suppose P(z, eᶻ) = 0 for every z, with P a polynomial in two variables. Fix the output w. The gold squares are infinitely many inputs with that same output, so the one-variable polynomial P(X, w) has infinitely many roots: it is the zero polynomial. This holds for every w ≠ 0, so every coefficient of P, a polynomial in w, has infinitely many roots too. Hence P = 0: the exponential function is transcendental.

A nonzero polynomial in one variable has only finitely many roots; a periodic function takes each of its values infinitely often. The same argument shows that sine and cosine are transcendental functions.
